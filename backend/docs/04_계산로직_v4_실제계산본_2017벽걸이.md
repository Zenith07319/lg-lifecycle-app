## 1단계: 상태 진단 지표

### 1-0. 증상 → 전력 증가율 합산 [04h]

선택 증상을 내부키로 변환 후, MDPI 대역을 선형 보간하고 **복수 합산**(최대 ×1.0 + 추가 ×0.8 중복보정).

```
증상_전력증가 = low + (high − low) × (심각도 − 1) / 4
  · 성능저하→냉방약화 sev3: 9.98 + (24.77−9.98)×(3−1)/4 = 17.375%   (가역비율 rev 0.6)
  · 소음           sev2: 5.76 + (13.41−5.76)×(2−1)/4 =  7.672%   (rev 0.2)
sym_total = 1.0×17.375 + 0.8×7.672 = 23.51%      # 최대 증상 1.0, 추가 0.8
sym_self  = 1.0×17.375×(1−0.6) + 0.8×7.672×(1−0.2) = 11.86%   # 셀프케어로도 안 빠지는 잔여
```

> 대표 증상(rep) = 위험도×심각도 최대 = **냉방약화** → VOC 조회·누수 안전규칙 등 이산 분기에만 사용.

### 1-1. 점검 필요도 (0~1)

```
연식_전력증가 perm = min(1.5%/년 × 9, 25) = 13.5%
필터_전력증가 fil  = min(9/12, 1) × 2.41% = 1.81%
복합보정 sf = (sym_total + fil) × 0.8 = (23.51 + 1.81) × 0.8 = 20.26   # 증상·필터 동시
배율(수리) m_repair = 1 + 0.1 × min(1, 3) = 1.1
배율(VOC) m_voc    = 1 + 0.3 × 0.91 = 1.273          # rep=냉방약화 VOC 0.91
P_TOTAL_MAX = 36.52 + 25.0 + 2.41 = 63.93

점검필요도 = min( (sf × m_repair × m_voc + perm) / P_TOTAL_MAX , 1 )
          = min( (20.26 × 1.1 × 1.273 + 13.5) / 63.93 , 1 )
          = min( 41.87 / 63.93 , 1 ) = 0.655          (= 66 / 100)
```

> 연식(perm)은 배율에 증폭되지 않고 증상·필터 블록(sf)에만 수리·VOC 배율을 적용한다([04g]).

### 1-2. 생활 불편도 (0~1)

> 현재 코드는 증상별 `불편도base × 심각도배율`을 [04h] 방식으로 합산(최대 1.0 + 추가 0.8) 후 연식 보너스.

```
냉방약화: 0.65 × 1.0(sev3) = 0.650
소음:     0.40 × 0.6(sev2) = 0.240
합산 = 1.0×0.650 + 0.8×0.240 = 0.842
+ 연식보너스(age_score × 0.10 = 0.539×0.10 = 0.054)
생활불편도 = min(0.842 + 0.054, 1.0) = 0.896
```

### 1-3. 에너지 낭비 (잔존효율 기반, ②안 [04g])

```
block = perm + sym_total + fil = 13.5 + 23.51 + 1.81 = 38.82%
잔존효율 ce = 1 / (1 + block/100) = 1 / 1.3882 = 0.7204
에너지낭비비율 = 1/ce − 1 = 0.388        (= 신품 자기 대비 39% 추가 소비)
```

> "건강"용 낭비비율은 **신품 자기 대비**(연식·증상·필터로 인한 추가 소비)다. 최신 1등급 신형 대비 격차는 2~3단계 비용층(교체 편익)에서만 쓴다.

### 1-4. 가전 건강등급 (A~E)

```
종합위험 raw = 점검필요도 × 0.45 + 에너지낭비 × 0.30 + 생활불편도 × 0.25
            = 0.655 × 0.45 + 0.388 × 0.30 + 0.896 × 0.25
            = 0.29475 + 0.11640 + 0.22400 = 0.6351
건강점수 = 100 − 63.51 = 36.5점
```

| 점수 | 등급 | 의미 |
|------|------|------|
| 80+ | A | 계속 사용 적합 |
| 65~79 | B | 셀프케어 권장 |
| 50~64 | C | 점검 권장 |
| **35~49** | **D** | **구독·교체 검토 ← 본 기기 (36.5)** |
| ~34 | E | 즉시 점검 또는 교체 권장 |

→ **건강 D등급 (36.5점)**.

## 2단계: 전기요금 계산 (에어컨 기여 델타)

```
구형 월소비(라벨 미입력 → 용량표 추정, [04j] 용량비례 보정 적용)
  → k_ac_old = 117.5 kWh/월

  구형 에어컨 월 기여요금 = 66,296원
  신형 에어컨 월 기여요금 = 12,655원
```

> 라벨값을 입력하면 추정 대신 실제값을 K_AC 베이스로 사용해 더 정확해진다.

## 3단계: 선택지별 5년 총비용 + 최종 점수

각 옵션 5년 총비용 = 전기비(연 1.5% 효율감퇴 반영) + 옵션 고유비용(셀프케어비/수리비/구독료/구매가).
부품보유기간(연식+8년 = 2025) **초과** → '수리 후 사용' final_score −0.20, 재수리 기대확률 0.406 반영.

| 순위 | 옵션 | 5년 총비용 | final_score | 경제 / 신뢰 / 탄소 / 편의 / 초기 |
|------|------|------|------|------|
| 1 | **구독 전환** | 3,201,128원 | **0.83** | 0.20 / 0.95 / 1.00 / 0.95 / 1.00 |
| 2 | 신제품 구매 | 1,411,128원 | 0.76 | 0.81 / 0.97 / 0.75 / 0.98 / 0.00 |
| 3 | 수리 후 사용 | 872,636원 | 0.63 | 0.97 / 0.71 / 0.73 / 0.87 / 0.71 |
| 4 | 셀프케어 후 사용 | 1,285,284원 | 0.63 | 0.81 / 0.54 / 0.40 / 0.41 / 0.97 |
| 5 | 계속 사용 | 1,356,232원 | 0.44 | 0.76 / 0.34 / 0.00 / 0.10 / 1.00 |

**왜 구독 1순위인가** — 우선순위에 비용(초기비용 민감)이 크고 점검필요도(0.655)가 높아
하드룰 **"비용 우선 + 점검 높음 → 구독 가점"**이 적용됨. 또 **부품보유 초과(−0.20)**로 전기비가
가장 싼 '수리 후 사용'이 3순위로 내려감(신뢰·부품 리스크 반영).

> 최종 추천: **1순위 구독 전환 / 2순위 신제품 구매** (`report.recommendation_1st/2nd`).

## 4단계: 탄소 영향

옵션별 5년 사용탄소 + 교체/수리 프록시 탄소로 회수기간 산정(3년/7년 임계). 본 예시는 점수표의 탄소 열에 반영.

## 5단계: 최종 점수 및 가중치

```
final_score = Σ (지표점수 × 지표가중치)
지표가중치 = 우선순위 3축(비용 40 / 환경 30 / 편의 30)을 5지표 가중치(합 1.0)로 변환
```

→ final_score 내림차순 정렬 + 하드룰 보정 → 위 3단계 랭킹표.

## 부록: 기존 에어컨 효율은 지금 몇 % 떨어졌나

### A. 결론
현재 잔존효율 **약 72.0%**(신품=100% 대비) → **효율 약 28.0% 감소** (= 신품 대비 약 39% 더 소비).

### B. 두 숫자의 차이
- **효율 감소율 28.0%** = 1 − η  (신품 100 대비 28 떨어짐)
- **추가 소비 38.8%** = 1/η − 1  (같은 냉방에 39% 더 먹음, = 결과화면 "에너지 낭비 39%")
- 효율 28%↓ → 1/0.72 ≈ 1.39배 소비. 둘은 동전의 양면.

### C. 계산
```
과소비율 block = 영구열화(연식) + 가역열화(증상 + 필터)
η = 1 / (1 + block/100),   효율감소 = 1 − η
```
원인별 과소비 분해(합산 38.82%p):

| 원인 | 과소비 | 비중 | 회복 가능? |
|------|------|------|------|
| 연식 영구열화 (1.5%/년 × 9년) | 13.5%p | 34.8% | ❌ 영구 |
| 증상 (냉방약화 17.4 + 0.8×소음 7.7) | 23.5%p | 60.6% | ✅ 수리 |
| 필터 미청소 9개월 | 1.8%p | 4.7% | ✅ 청소 |
| **합계(block)** | **38.8%p** | 100% | — |

```
η = 1/(1+38.82/100) = 0.720 → 효율감소 1−0.720 = 28.0%
```

### D. 조치 시 회복 (가역 vs 영구)

| 상태 | 잔존효율 η | 효율 감소 |
|------|------|------|
| 현재(계속 사용) | 72.0% | **−28.0%** |
| 셀프케어 후(필터+가역증상 일부 제거) | 79.8% | −20.2% |
| 수리 후(증상·필터 전량 해소 → 영구만) | 88.1% | −11.9% |
| (신품) | 100% | 0% |

> 떨어진 28% 중 **연식 ~12%p는 영구(회복 불가)**, **~16%p는 수리·청소로 회복** 가능. 수리해도 88%가 한계인 이유가 연식 영구열화.
