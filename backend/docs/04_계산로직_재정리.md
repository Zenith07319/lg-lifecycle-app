# 04. 계산 로직 (Calculation Logic) — v3 통일 앵커 구조 개정본

> 이 서비스의 모든 수치는 **현재 입력 조건 기준 추정 결과**다.
> 정확한 고장 예측이 아니며, 의사결정 참고용이다.
> "정확한 예측"이라는 표현은 절대 사용하지 않는다.

> **v3 설계 원칙 (신규)**
> 1. 진단층의 모든 측정량은 **소비전력 증가율(%)** 단일 단위로 환산한다.
> 2. 같은 단위는 가중치 없이 합산한다. 환산 불가능한 요인은 합산하지 않는다(배율 처리).
> 3. 모든 0~1 점수는 `min(측정량 ÷ 앵커, 1.0)` 형태를 따른다.
>    앵커 = "점수가 1.0이 되는 물리적 기준점"이며, **근거 증명은 앵커에만 요구된다.**
> 4. 가치판단(가중치)은 결정층에만 존재하며, 민감도 분석으로 방어한다.

## 기본 계산 기간

모든 비교는 **5년(여름 3개월 × 5년 = 15개월)** 기준으로 산정한다. [E5]

> 코드 기준: `src/scoring_v2.py` `COMPARISON_YEARS = 5`.
> `seasons = 3 × 5 = 15개월`, `sub_months = 60개월`.
> 근거 서술: 기대수명 16.7년의 약 1/3 시점이며 부품보유기간(8년) 이내 — 비교가 유효한 구간.
> ※ 탄소 회수 임계(3년/7년), 기대수명, 부품보유기간은 비교기간과 무관한 별도 상수.

## 1단계: 상태 진단 지표

### 1-0. 공통 공식

```
요인별 전력증가_i = 측정량_i 를 전력 증가율(%)로 환산
점검필요도 = min( Σ 전력증가_i / P_TOTAL_MAX , 1.0 ) × 배율(수리) × 배율(VOC)
           (최종에도 min(·, 1.0) 캡 적용)
```

- `min(·, 1.0)` 캡으로 0~1 범위가 구조적으로 보장된다 (구버전 상한 초과 버그 — 생활불편도 최대 1.43 — 해소).

### 1-1. 점검 필요도 (0~1)

> "고장 확률"이 아닌, 현재 입력 조건이 시사하는 **전력 열화 수준 기반 점검 필요도**다.

#### 1-1-1. 합산 요인 (전력 환산 가능 — 3종)

**① 증상 → 전력 증가율 추정** [E3]

사용자 입력(증상 종류 + 심각도 1~5)을 자체 실측 고장-전력 데이터의 대역으로 매핑한다.
구버전의 [증상 기본값 테이블 × 심각도 배율 테이블] 2단 곱 구조는 **폐지**한다.
(→ 무근거 상수 12개가 실측 대역 보간으로 대체. 5점 배율 1.8 TBD 항목도 자동 소멸.)

| 증상(명세서 라벨) | 전력증가 대역 (%) | 대역 근거 (자체 실측) |
|------|------|------|
| 증상없음 | 0 | 기준 (Faultless 1210.1W) |
| 냄새 | 2.41 ~ 5.76 | 필터 막힘 ~ 커패시터+필터 |
| 전기요금증가 | 2.41 ~ 8.33 | 필터 ~ 커패시터 노후 (요금 증가의 전형 원인 대역) |
| 소음 | 5.76 ~ 13.41 | 커패시터 계열 |
| 성능저하 | 9.98 ~ 24.77 | 콘덴서 막힘 30% ~ 60% |
| 누수 | 24.77 ~ 36.52 | 콘덴서 중증 ~ 복합 (안전 신호 가중) |
| 작동불량 | 36.52 (고정) | 실측 최대 (커패시터+콘덴서60%) |

```
증상_전력증가 = low + (high − low) × (심각도 − 1) / 4     # 심각도 1~5 선형 보간
```

> 구버전과의 순위 정합성: 작동불량 > 누수 > 성능저하 > 소음 > 전기요금 ≈ 냄새
> (냄새·전기요금만 순위 교환 — 실측 기준 정렬 결과).

**② 연식 → 전력 증가율 추정** [E2]

```
연식_전력증가 = min( 사용연수 × R_AGE_YR , R_AGE_MAX )
R_AGE_YR  = 1.5 %/년     # 문헌: 에어컨 연간 효율저하 1~2%의 중앙값 [인용 확보 필요]
R_AGE_MAX = 25 %          # = 1.5 × 16.7년 (기대수명 앵커와 정합)
```

> [정합화] 코드 효율감퇴 상수 −0.025/년은 문헌 범위 상단 초과 →
> 본 개정 채택 시 **−0.015/년**으로 조정해 진단층·비용층 감퇴율을 일치시킨다.
> [한계 명시] 연식 감퇴와 증상(막힘 등)은 부분적으로 동일 물리 현상을 공유 —
> 합산에 약간의 중복 가능. min 캡과 복합 보정(1-1-3)으로 완화.
> [민감도] R_AGE_YR 1.0~2.0%/년 변동 시 등급 변경률 7.5~9.4% (부록 B) —
> 중간 민감도이므로 문헌 인용 확보가 우선 보강 대상.

**③ 관리 미이행(필터) → 전력 증가율 추정** [E3+E2]

```
필터_전력증가 = min( 미청소_월수 / 12 , 1.0 ) × 2.41%
```

- 12개월 = 권장 청소주기 기준 "필터 50% 막힘" 도달 가정 [출처: 제조사 권장 청소주기]
- 2.41% = 필터 50% 막힘 자체 실측값
- 구버전 ×0.10(10개월 포화)과 근거 체인(12개월) 불일치 → **12개월로 통일**.
- [민감도] 주기 10~14개월 변동 시 등급 변경률 0.3~1.1% — 사실상 무영향 입증(부록 B).

#### 1-1-2. 도출되는 비율 (선택값이 아닌 계산 결과)

```
P_TOTAL_MAX = 36.52 + 25.0 + 2.41 = 63.93 %
```

| 요인 | 최대 영향 | 암묵 비율 |
|------|------|------|
| 증상 | 36.52% | 0.571 |
| 연식 | 25.0% | 0.391 |
| 관리 | 2.41% | 0.038 |

> 이 비율은 설정값이 아니라 **앵커들의 비율**이다. "왜 이 비율인가"라는 질문은
> "각 요인의 최대 전력 영향이 몇 %인가"라는 사실 질문으로 환원되며,
> 답은 실측(증상·관리)과 문헌(연식)에 있다.
> 구버전의 점검 가중치 5종(0.30/0.30/0.15/0.15/0.10)은 폐기한다.

#### 1-1-3. 복합 고장 보정 (자체 실측 검증) [E3]

단순 합산의 타당성을 자체 데이터로 검증했다. 복합 실측 / 단독 합:

| 조합 | 단독 합 | 복합 실측 | 비율 |
|------|------|------|------|
| 커패시터 + 필터 | 10.74% | 5.76% | 0.54 |
| 커패시터 + 콘덴서30% | 18.31% | 13.41% | 0.73 |
| 콘덴서60% + 필터 | 27.18% | 27.86% | 1.02 |

복합 고장은 대체로 부분 가산적(평균 ≈ 0.76) → 단순 합산은 보수(과대) 방향, min 캡이 상한 통제.
**채택**: 증상·필터 동시 발생 시 보정계수 0.8 적용 (등급 변경률 9.3% — 유의미, 실측 근거 보유).

```
if 증상_전력증가 > 0 and 필터_전력증가 > 0:
    고장합 = (증상_전력증가 + 필터_전력증가) × 0.8
```

#### 1-1-4. 배율 요인 (전력 환산 불가 — 2종) [E5]

전력 단위로 환산할 근거가 없는 요인은 점수에 **더하지 않고** 위험 증폭 배율로만 쓴다.

```
배율(수리) = 1.0 + 0.1 × min(수리횟수, 3)      # 1.0 ~ 1.3
배율(VOC)  = 1.0 + 0.3 × VOC점수               # 1.0 ~ 1.3, VOC점수 = 크롤링 빈도 min-max 정규화
```

- 수리: 수리이력↔재고장 상관 데이터 부재(확인됨). "3회 포화"는 정책 선언이며
  운영 데이터 축적 후 실증 전환 계획. [민감도] 단가 ±50% 시 변경률 4.7~6.0%.
- VOC: 빈도는 위험도가 아닌 **관심도** 신호 → 증폭 상한 ±30% 제한(보조 신호 원칙).
  [민감도] 상한 ±50% 시 변경률 5.9~7.2%.

### 1-2. 생활불편도 (0~1) — 직접 입력으로 전환

구버전 파생식(증상불편도 테이블 × 배율 + 연식×0.10)은 **폐지**한다.
점검필요도와 입력이 동일하고 계수 테이블 상관 r=0.93(Pearson 0.933/Spearman 0.929)인
중복 지표였으며, 종합위험에서 증상이 명목 13.5% 대비 실효 ~37%로 이중 계상되고 있었다.

```
생활불편도 = (사용자 응답 − 1) / 4
# 챗봇 설문: "이 증상이 생활에 얼마나 불편한가요? (1~5)"
```

- 같은 증상에도 사용자별 허용도가 다르다는 **독립 정보** 확보.
- 무근거 상수 8개(불편도 테이블 7 + 연식계수) 삭제.
- 5단계 '편의' 축이 실제 사용자 입력 기반이 되어 우선순위 3축 정당성 강화.

### 1-3. 에너지 낭비

```
낭비 kWh = max(구형_연간_kWh − 신형_연간_kWh, 0)
낭비 비율 = 낭비 kWh / 신형_연간_kWh
```

> [중복 아님 — 기준점 차이 명시] 점검필요도와 에너지낭비는 둘 다 전력 기반이지만
> 비교 기준이 다르다. 점검필요도 = **자기 신품 상태 대비** 열화(고장 신호),
> 에너지낭비 = **최신 1등급 신형 대비** 격차(교체 편익).

> **[검토 필요: 낭비비율 재정의]** 현 정의는 신품도 비율 ~0.43에서 시작해
> (NEW_EFF_RATIO 0.70 역수 효과) 건강한 5년차가 이 항만으로 16점 감점된다.
> 시뮬레이션 결과 A등급 도달률 1.2%, 정합성 페르소나(5년·무증상·관리양호)가 77.9점 B.
> 대안: ① 등급 컷 조정(A 80→75) ② 건강등급용 낭비비율을 "신품 자기 대비 추가 낭비"
> (연식 열화분)로 재정의하고, 신형 대비 격차는 비용층(교체 편익)에서만 사용. **②안 권장** —
> "건강" 개념과 정합(신형 대비 격차는 교체 편익이지 내 기기의 건강 문제가 아님).

**에어컨 월 소비전력 추정** (효율관리제도 '표준 월간 소비전력량' 기반) [E1]

```
K_AC_월(신품 기준) = 표준_월간_kWh × (실제_사용시간 / 7.8h)
실제 K_AC_월       = K_AC_월(신품 기준) ÷ 잔존효율 η     (구형만 η<1)
```

- 기준 7.8h/일 = 효율관리제도 냉방기간 표준 941h ÷ 4개월 ÷ 30일. [E1, 계산 체인 완비]
- 입력 우선순위: ① 사용자 라벨 직접 입력 → ② `device_energy_spec.csv` 폴백.
- NEW_EFF_RATIO = 0.70 [E2약 — 신고스펙 1등급/3등급 비 0.67~0.73.
  실제 추출 데이터(모델 수·분포) 부록 첨부 시 E1 격상]
- η 감퇴: **−0.015/년** (1-1-1 ②와 정합화), 하한 0.65.
- ⚠ 온도 비선형 한계 명시 유지 (사용시간 선형 보정 근사).

### 1-4. 가전 건강등급 (A~E) — 결정층

```
종합위험 = 점검필요도 × 0.45 + 에너지낭비비율 × 0.30 + 생활불편도 × 0.25
건강점수 = 100 − 종합위험 × 100
```

| 점수 | 등급 | 의미 |
|------|------|------|
| 80+ | A | 계속 사용 적합 |
| 65~79 | B | 셀프케어 권장 |
| 50~64 | C | 점검 권장 |
| 35~49 | D | 구독·교체 검토 |
| ~34 | E | 즉시 점검 또는 교체 권장 |

세 지표는 이질 지표(고장 신호 / 교체 편익 / 주관 불편)이므로 여기서부터는 **가치판단(E5)**이다.
방어 체계: ① MVP 정책 기본값 명시 선언 ② 민감도 분석 — 가중 ±50% 시 등급 변경률
9.2~25.1% (부록 B, **전체 파라미터 중 최고 민감도** → 방어 자원 집중 지점)
③ 등급 컷(80/65/50/35)은 1-3 낭비비율 재정의 결정 후 페르소나 분포로 보정.

## 2단계: 전기요금 계산

### 에어컨 기여 델타 방식 (유지)

```
K_AC_델타 = Bill(K_기준 + K_AC) − Bill(K_기준)
```

### 기본 공식

```
월 청구액 = 기본요금 + 전력량요금합계 + 기후환경요금 + 연료비조정요금
           + 부가세(10%) + 전력산업기반기금(2.7%)
```

> **[수정: 전력산업기반기금 3.7% → 2.7%]** 전기사업법 시행령 개정으로
> 3.7% → 3.2%(2024.7.1) → **2.7%(2025.7.1~)** 단계 인하. [E1]
> 기후환경요금(9.0원/kWh)·연료비조정요금(+5.0원/kWh)은 KEPCO 분기 고시값 —
> 최신 고시 재확인 필요. [E1 검증 필요]
> 요금표 기준일 갱신: 2025-04-01 → 최신 고시 기준일로.

(하계 주택용전력 고압/저압 요금표, 누진구간 비교 예시: 구버전 내용 유지 —
단, 예시 금액은 기금 2.7% 반영 재계산 필요)

## 3단계: 선택지별 에어컨 관련 5년 총비용 (델타 방식)

| 선택지 | 비용 구성 |
|--------|----------|
| ① 계속 사용 | 전기비_5년(구형) |
| ② 셀프케어 | 전기비_5년(구형) + 셀프케어비 × 5 |
| ③ 수리 후 사용 | 전기비_5년(구형) + 수리비 + 출장비 |
| ④ 구독 전환 | 구독료 × 60개월 + 전기비_5년(신형) |
| ⑤ 신제품 구매 | 구매가 + 전기비_5년(신형) |

단순 1차 산식 (효율 미반영):

```
② 셀프케어   = elec_old_5y × 0.976 + 셀프케어비_중간값 × 5
③ 수리후사용 = elec_old_5y × 0.75  + 수리비_중간값 + 출장비
```

> **[수정: 셀프케어 0.95 → 0.976]** 자체 실측: 필터 50% 막힘 1239.2W → 정상 1210.1W,
> 절감 상한 = 29.1/1239.2 = **2.35%**. 구 5%는 실측 상한의 2배 이상인 낙관값이었음.
> 근거가 "보수적 가정"에서 **"자체 실측 상한값"[E3]**으로 격상. [무근거 → E3]
>
> **[수정: 수리후 0.60 → 0.75]** 자체 실측: 최악 복합(1652.0W) → 정상(1210.1W) 완전 수리
> 가정에도 절감 상한 = **26.7%** (콘덴서60% 단독 19.9%). 구 40%는 물리적으로 도달 불가.
> 정밀화 옵션: 증상별 차등 (경증 ×0.95 / 중증 ×0.75). [무근거 → E3]
>
> 효율감퇴 시퀀스 정합화: 계속사용 매년 **−0.015**(구 −0.025, 1-1-1 ②와 일치),
> 셀프케어 +0.024 시작(실측 2.35% 정합), 수리후 0.75 절감 반영, 신형 1.0, 하한 0.65.

비용 기준값: 출장비 39,600 / 수리비 80,000~500,000(중간 290,000) / 구독 49,000×60 /
구매 1,000,000~1,300,000(중간 1,150,000) / 셀프케어 15,000~50,000(중간 32,500)×5.
[E1/E2 — LG 서비스 공시가, **조회 일자·URL 기록 추가 필요**]

### 수리 후 사용: 재수리 기대비용 (명칭 변경)

> **[수정: "재수리 확률" → "재수리 위험 보정계수"]** 점검필요도 × 연식점수의 곱은

```

```
