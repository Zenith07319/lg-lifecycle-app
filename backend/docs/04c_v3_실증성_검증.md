## 3) 한계점

### 치명적 (발표 시 즉시 붕괴)
- **SPOF**: watt 앵커 3종이 모든 분모 → 무너지면 진단·비용층 동시 붕괴, 원본 0개
- **순환 오류**: "근거는 앵커에만 요구"가 앵커 부재를 가림. 분자 미검증이면 비율 정당성 = 가중치 이하
- **방어선 공란**: E5 전체가 미실행 민감도에 위임 → "도구는?" 질문 하나에 붕괴
- **문헌 후퇴로도 막힘**: HVAC 논문에 해당 값 부재 → E2 변명도 불가

### 사실오류 / 자기모순
- "1.43 버그 해소" 허위(v2 이미 캡), "가치판단 제거" 과장(결정층 0.45/0.30/0.25 자인), r=0.93 "중복 입증" 과장(설계값 상관)

### 구조적 한계
- C1 출처 붕괴(효율논문 무관), 배출계수 최신성(0.4173), NEW_EFF 순환검증(N=3), 증상↔연식 물리 중복

### 구현 리스크
- **문서-코드 전면 불일치**: 기금/셀프케어/수리후/감퇴율/앵커비율 대부분 미구현(문서상 결정뿐)
- 감퇴율·절감상한 4~5곳 분산(동시수정 필요), 복수증상 합산=큰 수술, 프론트 가중치 하드코딩 SSOT 부재
