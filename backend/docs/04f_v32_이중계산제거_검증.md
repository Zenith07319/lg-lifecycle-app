## 0. 한 줄 요약

연간 효율 열화 5.2%를 **영구분(연식)**과 **가역분(증상·필터)**으로 분리하여, 같은 증상의 전력 증가가 두 번 계산되던 문제를 제거했다. 연식 항은 **영구 1.5%/년만**, 증상은 **MDPI 실측 대역으로 직접** 적용한다.

---

## 1. 근거: 두 실측 논문의 역할 분담

### 1-1. FSEC 2018 (efficiency.pdf) — 5.2%의 출처이자 분해 근거

Fenaughty & Parker, *"Evaluation of Air Conditioning Performance Degradation"* (Florida Solar Energy Center, ACEEE 2018). 플로리다 56가구를 2012–2016 서브미터링한 **장기 실측**(주거용 AC 성능저하 최초의 장기 실측).

- **연간 열화 중앙값 = 5.2%/년** (mean ~3.7%, 범위 −8~+40%) → 우리가 쓰던 5.2%의 **1차 출처 확정**(기존 가안 아님)
- 연식이 열화율에 **95% 신뢰수준 유의**, 무정비 시 2–3%/년(DOE Hendron 2006)
- 논문 제목 *"Opportunities from Diagnostic Methods"* — 열화 상당분이 **정비로 회복(가역)**됨을 실증

**분해 논리** (본 로직의 뼈대):
```
연간 열화 5.2% = 영구 ~1.5%/년 (압축기·부품 노화, 못 되돌림)
              + 가역 ~3.7%/년 (코일·필터 오염, 청소로 회복)
```

### 1-2. MDPI 2024 (air.pdf, ac_fault_detec.py) — 증상→전력 증가 실측

split AC 전류·전압 실측. 고장유형별 baseline(1210.1W) 대비 전력 증가율:

| 증상(내부키) | 전력 증가 대역(%) | 물리 원인 |
|---|---|---|
| 냄새 | 2.41 ~ 5.76 | 코일 오염·곰팡이 |
| 전기료부담 | 2.41 ~ 8.33 | 커패시터 노후 등 |
| 소음 | 5.76 ~ 13.41 | 팬·모터·커패시터 |
| 냉방약화 | 9.98 ~ 24.77 | 콘덴서 막힘 |
| 작동불가 | 24.77 ~ 36.52 | 복합 고장 |
| 필터(FI50) | +2.41 | 필터 50% 막힘 |

### 1-3. 두 논문의 관계 = "합산"이 아니라 "역할 분담"

- **FSEC = 시간축(rate)**: 1년에 몇 %씩 나빠지는가
- **MDPI = 상태축(state)**: 지금 이 증상이면 몇 % 더 쓰는가 (시간 개념 없음)

→ 두 데이터를 **더하면 안 된다**(다른 축). MDPI의 가역 고장(콘덴서·필터)은 FSEC가 말하는 "가역 3.7%"의 **물리적 정체**다. 같은 현상을 ⓐ MDPI로 현재 상태, ⓑ FSEC로 누적 속도 측정.

## 2. 왜 v3.1은 이중계산이었나

v3.1 에너지층:
```
η감퇴율 = 1.5%(영구) + 3.7%(가역) × 정비미흡도        ← 정비미흡도가 '증상심각도' 포함
```
그런데 증상의 전력 증가는 **MDPI가 이미 직접 측정**(점검층). 같은 가역 열화를 한 번은 MDPI(직접관측), 한 번은 FSEC 3.7%×증상(통계추측)으로 **두 번** 계산 → 이중계산.

> **원칙: 직접 관측값(증상 신고)이 있으면, 통계적 추측(연식×3.7%)을 더하지 않는다.**

## 3. v3.2 재정립 사양

### 3-1. 효율 과소비율 분해 (에너지층)

```
전력 과소비율 = 영구열화  +  가역열화
영구열화 = min(1.5%/년 × 연식, 25%)        ← FSEC 영구분. 상한 25% = 1.5% × 16.7년(KESIS 기대수명)
가역열화 = MDPI 증상대역%  +  필터%          ← 직접 측정 (추측 아님)

현재효율 η = 1 / (1 + 전력 과소비율)
```

### 3-2. 증상별 가역비율 (셀프/수리 효과 분리)

청소(셀프케어)로 회복되는 몫 = `가역비율`. 나머지는 수리(영구·부품) 영역.

| 증상 | 가역비율 | 근거 |
|---|---|---|
| 냄새 | 1.0 | 코일·곰팡이 오염 → 청소로 완전 회복 |
| 전기료부담 | 0.7 | 오염+부품노후 혼재 |
| 냉방약화 | 0.6 | 콘덴서 오염(가역)+냉매/압축기(영구) |
| 소음 | 0.2 | 대부분 기계부품(커패시터·모터) → 수리 |
| 작동불가 | 0.0 | 복합 고장 → 수리/교체 |
| 누수 | 0.0 | 배수·설치 → 수리(안전) |

> ⚠️ **가안(modeling assumption)**: 위 가역비율은 물리적 추정이며 실측 분해가 아니다.

### 3-3. 옵션별 효율 (미래 5년은 전부 영구 1.5%/년)

| 옵션 | 시작 효율 | 의미 |
|---|---|---|
| 계속사용 | η = 1/(1+영구+증상+필터) | 현 상태 유지 |
| 셀프케어 | 1/(1+영구+증상×(1−가역)) | 가역증상+필터 청소 제거 |
| 수리후 | 1/(1+영구) | 증상·필터 전량 해소 |
| 신형 | 1.0 | — |

미래 궤적은 모든 옵션이 **영구 1.5%/년**으로만 감퇴(가역분 재증식은 데이터 없어 미적용=보수적).

### 3-4. 옵션 완화효과도 가역율 일관 적용 (점검도·불편)

```
셀프 해소비율 sc_eff = (가역증상 + 필터) / 전력블록(증상+연식+필터)
수리 해소비율 rp_eff = (전체증상 + 필터) / 전력블록
점검도_after(셀프) = 점검도 × (1 − 0.85·sc_eff)
점검도_after(수리) = 점검도 × (1 − 0.85·rp_eff)
```
→ 냄새(가역1.0): 셀프 해소 = 수리 해소 → **셀프가 1순위**(수리 불필요).
→ 소음(가역0.2): 수리 해소 ≫ 셀프 → **수리/교체 우위**.

### 3-5. 점검필요도(층1)·정규화(층3)는 04c/04d 유지

- 점검필요도 = 0.75×전력열화블록 + 0.15×수리이력 + 0.10×VOC (연식 1.5% 동일 적용)
- 정규화: 0~1 지표 절대값 + floor 0.20 (04d 버그수정)
- 누수: 점검도 floor 0.55 + 파이프라인 최종단 수리 1순위 고정(안전 정책)

## 5. 남은 가안 (실측 아님 — 명시)

| 항목 | 값 | 성격 |
|---|---|---|
| 영구/가역 분해비 | 1.5% / 3.7% | FSEC median에서 역산(추정) |
| 증상별 가역비율 | 1.0/0.7/0.6/0.2/0 | 물리 추정 |
| 완화계수 | 0.85, 0.30, 0.7 | 모델 튜닝값 |
| 누수 floor / VOC가중 / 수리이력 | 0.55 / 0.10 / 0.33·회 | 04c부터 이월된 가안 |

> 구조(전력 통일·영구가역 분리)는 실측 앵커이나, 위 계수는 가안. 데모·발표 시 "정확한 고장 예측 아님" 고지 유지(절대원칙).
