## 0. 배경

팀 v4와 본 검토(v3.2)는 **핵심 골격이 수렴**(전력 % 통일 / 연식 1.5%·상한25% / MDPI 증상밴드 / 효율감퇴 −0.015)했으나, **이중계산 처리에서 갈렸다**:
- **v4**: 점검층에서 연식+증상 합산, "약간 중복 인정 → min캡·복합보정 0.8로 완화"
- **v3.2**: 연식=영구만 / 증상=가역 직접 → **완전 분리**(에너지층)

5개 쟁점을 합당성 판정 후 **베스트 조합**으로 통합했다.

## 2. 베스트 조합 사양

### 2-1. 점검필요도 (v4 골격 + 배율 보정)

```
증상% = MDPI 대역 보간(심각도 1~5)        # 0 ~ 36.52
연식% = min(1.5%/년 × 연식, 25%)          # 영구분
필터% = min(개월/12, 1) × 2.41%
sf    = (증상% + 필터%) × 0.8  if 증상>0 and 필터>0  else (증상%+필터%)   # 복합보정
배율_수리 = 1 + 0.1 × min(수리횟수, 3)      # 1.0~1.3
배율_VOC  = 1 + 0.3 × VOC                  # 1.0~1.3
점검필요도 = min( (sf × 배율_수리 × 배율_VOC + 연식%) / 63.93 , 1.0 )
            # 배율은 sf(증상·필터)에만 — 연식 미증폭
누수: max(점검필요도, 0.55)
```

### 2-2. 에너지 효율 (D1 분리 — 핵심)

```
전력 과소비% = 영구열화(연식 1.5%/년, 상한25%) + 가역열화(증상 MDPI + 필터)
현재효율 η = 1 / (1 + 과소비%/100)

옵션별 시작효율:
  계속 : η = 1/(1+영구+증상+필터)
  셀프 : 1/(1+영구+증상×(1−가역율))     # 가역증상+필터 청소 제거
  수리 : 1/(1+영구)                      # 증상·필터 전량 해소
  신형 : 1.0
미래 5년: 전 옵션 영구 1.5%/년만 감퇴 (가역 재증식 데이터 없음 = 보수)
```

증상별 가역율: 냄새 1.0 / 전기료 0.7 / 냉방약화 0.6 / 소음 0.2 / 작동·누수 0  [E5 가안]

### 2-3. 옵션 완화·정규화 (04d + 가역 일관)

```
셀프 해소비율 sc_eff = (가역증상+필터) / 전력블록
수리 해소비율 rp_eff = (전체증상+필터) / 전력블록
점검도_after(셀프) = 점검도 × (1 − 0.85·sc_eff)
점검도_after(수리) = 점검도 × (1 − 0.85·rp_eff)
낭비비율 = 1/η − 1 (신품 자기대비, ②안)
정규화: 0~1 지표 절대값 + floor 0.20 (min-max 증폭 버그 수정)
누수: 파이프라인 최종단 수리 1순위 고정(안전 정책)
```
