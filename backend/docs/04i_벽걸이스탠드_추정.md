# 04i. 벽걸이 / 스탠드 폼팩터 추정 (Form Factor Inference)

> 적용일: 2026-06-14 · 함수: `src/calculations_v2.py::classify_form`
> 입력: 냉방용량(`capacity_kw`) + 월간소비전력량 라벨(`ac_monthly_kwh_input`) → 출력: 폼팩터 + 신뢰도

## 1. 질문 — 입력값으로 벽걸이/스탠드 구분이 되나?

설문은 냉방용량과 월간소비전력량(라벨)을 입력받는다. 이 둘로 벽걸이/스탠드 판별이 가능한지
**LG 에어컨 카탈로그 132개**(벽걸이 26 · 스탠드 106) 분포로 검증했다.

| 폼 | n | 냉방용량 범위 | 중앙 | 평균 |
|---|---|---|---|---|
| 벽걸이 | 26 | 2.3 ~ 6.5 kW | 3.6 | 3.77 |
| 스탠드 | 106 | 6.5 ~ 9.0 kW | 7.2 | 7.32 |

벽걸이는 대부분 ≤5.2kW, 스탠드는 전부 ≥6.5kW로 **겹침이 6.5kW 한 점뿐**.
→ **냉방용량만으로 충분히 구분 가능.**

## 2. 기준점 — 임계 5.5kW

용량 임계별 분류 정확도(카탈로그 132개, `cap < thr → 벽걸이`):

| 임계 | 4.0 | 4.75 | 5.0 | **5.25~6.5** |
|---|---|---|---|---|
| 정확도 | 93.2% | 95.5% | 95.5% | **97.7%** |

5.25~6.5kW 구간이 모두 97.7%(오분류는 6.5kW급 대형 벽걸이 2~3대뿐). 보수적으로 가운데값
**5.5kW**를 1차 임계로 채택. **냉방용량 ≥ 5.5kW → 스탠드, 미만 → 벽걸이.**

## 3. 월간소비전력량(라벨)의 역할 — 보조 신호

용량 ↔ 월간소비전력량 상관 0.71(device_energy_spec). 용량과 강하게 연동되므로
**단독 1차 기준으로는 부적합**(용량이 더 정확). 다음 두 경우의 **보조 신호**로만 사용:

1. **애매구간 보정** — 용량 4.5~6.5kW(경계)에서 라벨 월간소비전력량이 명확하면 보정:
   - 월간소비전력량 ≥ 180 kWh/월 → 스탠드
   - 월간소비전력량 ≤ 110 kWh/월 → 벽걸이
2. **용량 미입력 시 단독 추정** — 월간소비전력량 ≥ 150 → 스탠드, 미만 → 벽걸이 (신뢰도 low)

## 4. 알고리즘 (`classify_form`) — 반환 (form, confidence)

```
용량 > 0:
    form = 스탠드 if 용량 ≥ 5.5 else 벽걸이
    if 4.5 ≤ 용량 ≤ 6.5 (애매):
        kWh ≥ 180 → (스탠드, medium)
        0 < kWh ≤ 110 → (벽걸이, medium)
        else → (form, medium)
    else → (form, high)
용량 미입력, kWh > 0:  (스탠드 if kWh ≥ 150 else 벽걸이, low)
정보 없음:            (벽걸이, low)   # 카탈로그 최빈 형태
```

## 5. 노출 경로
- `run_full_pipeline` → `result["form_estimated"]`/`["form_confidence"]`, `inputs["form_estimated"]`(세션 저장).
- `POST /api/diagnose` 응답에 `form_estimated`/`form_confidence` 추가.
- 프론트: 결과 페이지·`내 가전` 카드에 "벽걸이/스탠드 에어컨" 표기, `SavedDevice.form` 저장.

## 6. 한계 / 후속
- 임계 5.5kW는 **현행 LG 판매 카탈로그** 분포 기준. 구형·타사 대형 벽걸이(2-in-1, ~6.5kW)는 스탠드로 오분류 가능(전체 ~2.3%).
- 월간소비전력량 임계(180/110/150)는 device_energy_spec 표본(12행)이 작아 잠정값. 라벨 데이터 확보 시 재튜닝.
