# 04j. 월간소비전력량 폴백의 용량 비례 보정 (Capacity-Scaled Fallback)

> 적용일: 2026-06-14 · 함수: `app/services/calculation.py::run_full_pipeline`
> 관련: 스탠드 폼팩터 [04i](04i_벽걸이스탠드_추정.md)

## 1. 버그 — 스탠드 에어컨 전기세 과소평가

에너지 베이스(`old_monthly_kwh`)는 **라벨 월간소비전력량 입력값 우선**, 미입력 시 `device_energy_spec`
표에서 가장 가까운 용량 레코드로 폴백한다. 그런데 표(에어컨)는 **2.5~5.0kW 12행뿐**이라
스탠드 용량(6.5~9.0kW)이 없다.

→ 7.2kW·9.0kW 스탠드가 라벨 미입력으로 진단되면 폴백이 **5.0kW에서 멈춰** 동일한 173kWh로 계산.
   전기세가 5.0kW급으로 과소평가(약 -40%). 새 설문에서 월간소비전력량은 선택 입력이라 빈발.

| 용량 | 수정 전 폴백 k_old | 월 추가요금 |
|---|---|---|
| 5.0kW | 173 kWh | 83,111원 |
| 7.2kW(스탠드) | 173 kWh (동일) | 83,111원 |
| 9.0kW(스탠드) | 173 kWh (동일) | 83,111원 |

## 2. 수정 — 용량 비례 보정

동일 효율급에서 **월간소비전력량 ∝ 냉방용량**(EER 일정 → 전력 ∝ 냉방능력)이므로,
폴백 레코드의 월간소비전력량을 `입력용량 / 스펙용량` 비로 보정한다(0.5~4.0배 클램프).

```python
base_kwh = old_spec["monthly_kwh"]
spec_cap = old_spec["capacity_kw"]
ratio = clamp(cap / spec_cap, 0.5, 4.0)
old_monthly_kwh = base_kwh * ratio
```

표 범위 안(2.5~5.0kW)은 가장 가까운 레코드라 ratio≈1 → **기존과 동일(회귀 안전)**.
표 범위 밖(스탠드)은 용량에 비례해 외삽.

| 용량 | 수정 후 폴백 k_old | 월 추가요금 |
|---|---|---|
| 5.0kW | 173 kWh | 83,111원 (불변) |
| 7.2kW | **249 kWh** | **105,345원** |
| 9.0kW | **312 kWh** | **123,500원** |
| (참고) 7.2kW+라벨250 | 289 kWh | 116,769원 |

폴백값(249)이 라벨 기반(289)에 근접 — 라벨이 더 정확하므로 입력 권장은 유지.

## 3. 근본 해결 (2026-06-14 추가)
비례 외삽은 동일 효율급 가정의 근사라, **`device_energy_spec`에 스탠드/대형 용량 행 13개 추가**로 데이터 소스를 보강했다.
- 출처: LG 공식 카탈로그(268개) 실제 **정격냉방소비전력**에서 `monthly_kwh = 정격전력(kW)×80h` 환산(04i와 동일 계수).
- 용량 커버 **2.5~5.0 → 2.5~9.0kW**. 스탠드 용량은 이제 가장 가까운 실데이터 행을 직접 사용(ratio≈1 → 비례보정 비활성).
- 비례 외삽(§2)은 표에 없는 중간 용량(예: 7.85kW) 보간용으로 유지.
- `source="LG스펙환산_2026"`로 표시(에너지공단 실측 행과 구분). 연식·등급은 모델코드 세대문자·COP 기반 보정값.
- 조사 원본 정리: `자료/LG에어컨_스펙조사.{csv,md}`.

## 4. 한계 / 후속
- 추가 행의 monthly_kwh는 **정격전력 기반 환산값**(실측 라벨 아님). 등급·연식은 코드·COP 추정.
- 클램프 상한 4.0배는 비정상 대용량 입력(상업용) 방어용.
