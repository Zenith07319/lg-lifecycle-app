# Figma 디자인 코드 보관소 (ROR × LG ThinQ UI)

팀원이 Figma에서 구현한 전체 UI를 "Figma to Code(React/inline style)"로 추출한 원본 코드 모음.
**목적**: 샘플 프론트 → 이 디자인으로 전면 교체할 때 화면별 원본을 바로 찾아보기 위함.
원본 파일: `_figma/screens/<id>.jsx` (절대좌표 inline-style, 390×844 고정).

> ⚠️ 추출 코드는 **절대좌표 + 하드코딩 데이터**다. 이식 시 ① 반응형/Tailwind 정리 ② 실제 API 데이터 연결 ③ 에셋(placehold.co → 실제) 교체가 필요. (작업 원칙은 [[../app/result 이식 사례]] 참고)

## 3. 모든 화면 공통 요소 (재사용 컴포넌트로 뽑을 것)

1. **iOS 상태바** (top 0, h44, "9:41" + 배터리) — 모든 화면 동일. 실제 앱에선 **제거**(브라우저 PWA라 불필요).
2. **하단 탭바** (top 766, h78, 흰 배경, shadow) — 홈/진단/내가전/더보기, 활성=틸 `#047D86`. → `BottomNav` 컴포넌트로 1회 작성.
3. **블롭 배경** (틸/그린 원형 5개, opacity .5, blur 90px) — Home·진단·알림 등. 좌표 고정 5블록. → `<AmbientBlobs>` 컴포넌트.
4. **헤더 패턴**: 큰 제목(26px 700) + 회색 부제(12px Noto Sans). 결과 플로우는 좌상단 백버튼(􀆉) + 가운데 "진단 결과/결정 가이드".
5. **유리 카드**: `bg rgba(255,255,255,.32~.8) + blur(15px) + radius 16~20`. → `<GlassCard>`.
6. **칩/뱃지**: 틸 채움 활성칩, "LG 연계"(빨강 점+테두리), 탄소 뱃지(연녹 bg "나무 N그루 효과 · N.NtCO₂").

## 4. 화면별 핵심 데이터(우리 API 연결 지점)

- **04-2 상세**: 건강점수(32)·에너지등급(E)·설치N년차·전기요금 내에어컨(99,681)↔1등급신형(40,931)·입력값기준뱃지·5년절감(1,175,000)·누진구간(451→301~450)·점검필요도(69)·에너지낭비(43%). + 에어컨일러스트·아바타(placehold.co → 실제 에셋).
- **04-1 판단근거**: 사용기간(12년)·수리이력(1회)·주요증상(특이없음)·점검필요도(69점)·필터미교체(9개월)·에너지효율(+43%) 6행 리스트 + 종합추천(신제품구매) + 그린 요약바.
- **04-3~7 결정가이드**: 순위별 옵션명·점수(85/75/56/52/47)·5년비용(₩1,986,740 등)·초기비용·옵션별 경고카드(부품보유 초과/필터세척키트 등). 우측 1~5 원형 셀렉터.
- **07-5 추천신제품**: 모델명·코드·평형·등급·가격·정가·평점·리뷰수·탄소(나무N그루/N.NtCO₂)·LG링크. (우리 `CatalogItem`과 매핑)
